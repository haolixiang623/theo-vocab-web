# 真经刷词神器 · Web 版

基于「Theo哥哥词汇真经学习工具」开发的 Web 版本词汇刷记工具。纯静态站点（原生 HTML/CSS/JS），**零依赖、零构建**，所有源码均在本文件夹内。

## 快速开始

方式一：直接打开（无需安装任何环境）

```
双击 index.html 即可在浏览器中使用（推荐 Chrome / Edge / Firefox）
```

方式二：本地HTTP服务（推荐，语音功能更稳定）

```bash
cd theo-vocab-web
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 📚 22 章词汇 | 共 3568 词，顶部下拉切换章节 |
| 📖 看中文 | 根据中文释义拼写单词 |
| 🔊 听音 | 播放发音后拼写，不显示中文 |
| 🎲 随机 | 每题随机「看中文 / 听音」 |
| ⌨️ 软键盘 | 触屏设备可用屏幕键盘输入（⇧ 大写、⌫ 退格、⏎ 提交） |
| 💡 提示 | 自动填入首字母，降低初期难度 |
| ⏱️ 计时 | 每题 10 秒，归零自动判错 |
| 🎯 每日目标 | 默认 50 词/天，可自定义，完成有庆祝动画 |
| 📕 错题本 | 答错自动收录，去重保存 |
| 📗 生词本 | 手动收藏，点击可发音 |
| 📚 复习模式 | 错题 + 生词合并为新题库 |
| 📋 词汇总览 | 侧边栏搜索单词/释义，显示掌握状态，点击跳转练习 |
| 📊 学习报告 | 完成本章后弹出，正确率 / 薄弱词，可导出 txt |
| 🌓 深色模式 | 标题旁月亮图标切换 |
| 💾 自动保存 | 进度、设置、单词本全部存于浏览器 localStorage，刷新不丢失 |

## 快捷键

- `回车`：提交答案 / 下一题
- `字母键 / - / 空格`：输入
- `Backspace`：退格删除

## 目录结构

```
theo-vocab-web/
├── index.html            # 应用入口（页面结构）
├── css/
│   └── style.css         # 全部样式（浅色/深色/响应式）
├── js/
│   ├── data.js           # 词汇数据（由 tools/merge-data.mjs 生成，3568 词）
│   └── app.js            # 应用逻辑（原生 JS，无框架）
├── tools/
│   ├── merge-data.mjs    # 数据合并脚本（旧版 22 个 data-x.js → js/data.js）
│   └── selftest.html     # 自动化自检页（37 项断言：答题/单词本/侧边栏/持久化）
└── README.md
```

## 重新生成词汇数据

如果旧版工具的数据有更新，重新执行：

```bash
node tools/merge-data.mjs "../我的Theo词汇真经学习工具" "js/data.js"
```

## 运行自检

```bash
# 在项目根目录起服务后访问
open http://localhost:8000/tools/selftest.html
# 页面左上角会输出 PASS/FAIL 汇总，全部通过应显示 ALL PASS
```

## 数据说明

- 词汇内容来自 B 站课程「Theo哥哥教雅思」，仅供学习交流。
- 每个单词包含：英文、音标、词性、中文释义、标签（核心/高频/识记/低频）、词根拆解、双语例句、拓展笔记。
- 掌握度规则：本章内答对 ≥ 2 次记为「✓ 掌握」。

## 浏览器兼容

- Chrome / Edge / Firefox / Safari 最新版
- 发音使用浏览器内置 SpeechSynthesis（需系统具备英语语音包）
- 音效使用 Web Audio API
